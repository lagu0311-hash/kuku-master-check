# 九九マスターチェック

小学2年生向けの、端末内完結型・九九チェックアプリです。主に **Androidタブレット＋Google Chrome** で使う想定です。iPhone・iPad・PCのブラウザにも対応します。

- 1×1〜9×9の81問を正しい順序付きで管理
- 練習は段ごと9問／まぜこぜ10・20問／にがて優先10・20問。力試しは全81問のランダム出題のみ
- れんしゅう（逐次解説）／ちからだめし（終了後に結果）の2モード
- 習得度4段階・保護者用の9×9習得マップと段別集計
- 端末ごとに `localStorage` （新形式v4）へ保存、JSONバックアップ・復元、CSV出力
- 正解時は絵本風の喜ぶ猫と紙吹雪、不正解時はコミカルな筋トレ動物（猫・犬・リス・ウサギ）
- ちからだめし結果は6区分の演出（満点は特別版）
- 81問の力試しで満点を取るたび、ごほうび絵の4マスがランダム順に1つ開く（4枚×4マス、合計16回で完成）
- 保護者向けに演出「ふつう／ひかえめ／オフ」切り替え
- 外部API・アカウント登録・広告・解析サービスなし

**開発状態（v1.4 第3段階・採用原画利用版）**：第2段階の機能修正を維持し、採用済みの水彩風イラストからキャラクター素材を切り出して動物表示へ組み込んだ。Android Chrome実機の最終確認・公開判断は未実施。`main`への統合・公開は未実施です。

## 公開方法（GitHub Pages）

1. GitHubで新しい公開リポジトリ `kuku-master-check` を作る（他のリポジトリは流用しない）。
2. このフォルダの内容をリポジトリの `main` ブランチに入れる。
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch** に設定。
4. **Branch: main / Folder: /docs** を選んで保存。
5. Pages画面の「Visit site」から開く。想定される公開URLは `https://<GitHubユーザー名>.github.io/kuku-master-check/`。実際のURLは公開後にGitHub上で確認する。

公開されるのはHTML/CSS/JavaScriptのコードです。学習記録はGitHubにアップロードしません。GitHub Pages自体は一般公開されるため、非公開の文書や児童の情報をリポジトリへ登録しないでください。

## 開発・動作確認

```bash
npm test
python -m http.server 8000 --directory docs
```

ブラウザで `http://localhost:8000` を開きます。JavaScriptのES Modulesを使うため、`file://` 直開きはしないでください。静的サイトなのでビルド不要、外部ライブラリ不要です。

## 保存・バックアップ上の注意

端末・ブラウザ・ブラウザの保存領域ごとに学習記録は独立します。Safariなどの履歴・サイトデータ削除、プライベートブラウズ、保存容量不足ではデータが失われることがあります。定期的に保護者画面からJSONバックアップを保存してください。別端末で復元すると、その端末の学習記録はバックアップで**上書き**されます（自動結合・同期はしません）。

## 学習判定の仕様

`ちからだめし`の履歴のみを習得状態に使用します。

- 未出題：まだ挑戦していない
- れんしゅう中：直近のちからだめしが不正解
- おぼえてきた：直近は正解だが、正解した日が1日のみ
- ばっちり：異なる2日以上に正解し、直近も正解

回答時間は参考情報のみで、習得状態の判定には含みません。計測は可視タブ内の問題表示から回答確定まで。バックグラウンド時と休憩中は停止します。

## ごほうび絵について

「ちからだめし」で**全81問正解（81/81）**になったセッションにつき1マス解放します。1枚は2×2の4マスで、4回満点で完成。4枚は花畑の猫→星空の猫→動物ピクニック→青い風船の猫の順で、合計16回満点でコンプリートです。各絵の開く順序はランダムに保存され、同一セッションを二重計上しません。「れんしゅう」や満点未満では開きません。

v4では旧v1〜v3の学習記録を自動で引き継ぎません。旧形式JSONバックアップも読み込みません。v4で作ったJSONバックアップは復元でき、CSV書き出しは維持します。

## プロジェクト構成

- `docs/`：GitHub Pages公開用の静的サイト
- `docs/core.js`：出題・習得判定・ごほうび進捗・検証・CSV等の純粋ロジック
- `docs/animals.js`：採用済み原画から切り出したローカルWebP素材（`docs/assets/characters/`）への表示割り当てと既存アニメーション連携
- `docs/assets/reward-{flower,stars,picnic,balloon}{,-still}.svg`：4枚の絵本風ごほうび原画と静止版（すべてオリジナル）
- `docs/app.js`：画面・キーボード／タッチ操作・端末内記録
- `docs/styles.css`：スマホ・タブレット・PC用レスポンシブデザイン
- `tests/`：Node標準テストランナーによるロジックテスト
- `DESIGN.md`：確定仕様と受け入れ基準

## 利用範囲

学習支援のための非標準化テストであり、教育評価尺度としての妥当性検証をしたものではありません。
